# Museum Website – Responsive Design

## Project Overview
This project is a responsive Museum Website designed using HTML and CSS, inspired by a Figma UI design. It showcases a collection of historical paintings and portraits through an elegant gallery-style layout.

## Features
- Responsive layout for desktop, tablet, and mobile devices.
- Navigation bar with Company, Collections, Menu, Events, and Contact links.
- Four artwork cards with images and descriptions.
- Google Fonts – Inter typography.
- Hover animations on cards, navigation links, and arrows.
- CSS Grid and Flexbox for layout management.
- Rounded cards, borders, padding, and custom color styling.

## Technologies Used
- HTML5
- CSS3
- Google Fonts (Inter)
- CSS Grid
- Flexbox
- Media Queries
- GitHub Pages

## Responsive Design
The website is optimized for:
- Desktop screens
- Tablet screens
- Mobile screens

CSS media queries are used to adjust the gallery layout and navigation according to screen size.

## Hover Effects
- Navigation links change background and text colors.
- Gallery cards move slightly upward on hover.
- Arrow icons animate horizontally.
- Smooth transitions improve user interaction.
